03 / PRACTICE

Password hygiene

  • Use a unique password for each account.
  • Prefer long, randomly selected passphrases.
  • Store them in a reputable password manager.
  • Enable MFA where available.
  • Change a password when compromise is suspected.

THE IMPORTANT IDEA

Length + unpredictability
beats a checklist.

“Password123!” mixes character types but combines a common word with a predictable number. A long, unique password or random-word passphrase is usually easier to assess than composition rules alone. Strength is an estimate, not a guarantee.

01

Use unique credentials

Reuse enables credential stuffing: attackers try leaked username/password pairs on other services.

02

Add another factor

MFA can reduce account takeover risk even when a password is exposed.

03

Store safely

Real services store salted, slow password hashes such as Argon2id, bcrypt, scrypt, or PBKDF2—not plaintext.
